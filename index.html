Sampling mode

Connect or enter Demo mode to choose a sampling mode.

Choose a mode before starting a recording. Stop the recording to change modes; the connection stays open. Focused mode prioritizes verified Bank 1 O2 voltages, Bank 1 fuel trims and RPM. Other dashboard values update less often. Achieved rates depend on the adapter and ECU; faster polling does not guarantee a diagnostic-quality O2 waveform.

Export a stopped recording

Export before reloading: recordings and report previews exist only in this tab. Both exports use the complete stopped recording, regardless of the graph time range. Known identifiers and VIN-like text are redacted when omission is selected; arbitrary personal details in notes cannot be detected reliably.

Trouble codes appear only if the existing Re-read action completed during that recording. Export sends no vehicle commands. CSV contains a recording metadata row (including notes, if selected), then every recorded result.

Diagnostic graphs

Start a diagnostic recording to graph the recorded measurements.

Each filled marker is an actual recorded measurement. Points are not connected, smoothed, or interpolated. Open circles below the plot mark missing results; crosses mark failed or unplottable results. Blue circles and orange squares distinguish the series. Graphs use recorded native units.

Oxygen readings are sparse and acquired sequentially. Unobserved changes between points are unknown; these graphs cannot establish switching speed, simultaneous sensor behavior, or catalytic-converter failure. Check the achieved rate and measurement times before interpreting a pattern.

Clear trouble codes?

This sends mode 04: it erases stored & pending codes, turns the check-engine light off, and resets all readiness monitors. The car will need a full drive cycle (often several days of mixed driving) before it can pass an emissions inspection again. It does not fix whatever set the code.
